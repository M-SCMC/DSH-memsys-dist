# 示例项目

这是六层记忆系统的最小示例库。删掉它，换成你自己的内容即可。

## 这个例子里有什么

- 一条语义记忆（本页）
- 一条决策（`20-决策/ADR-0001-示例决策.md`）
- 一条程序记忆（`30-习惯/procedures/P-0001-示例流程.md`）
- 一条情景记忆（`40-归档/episodes/` 下，用命令生成）

## 试试这些命令

export MEM_VAULT=$(pwd)

# 看目录
node 99-系统/记忆系统/tools/mem.mjs index

# 开场简报

# 检索 + 联想
